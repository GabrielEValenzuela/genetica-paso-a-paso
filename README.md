# Genética paso a paso

Guía de estudio interactiva de genética (ciclo celular, cromosomas y ADN, vocabulario, leyes de Mendel y sus extensiones), con problemas resueltos paso a paso, práctica con autoevaluación de confianza, entrenador de cuadros de Punnett y simulacro cronometrado.

Sitio estático: `index.html` + `assets/`. Se publica con GitHub Pages desde la rama `main`.
